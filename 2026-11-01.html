Titular del día

Las Agent Skills pasan a ser un estándar abierto: una misma "habilidad" para tu asistente de IA ya funciona en Claude, ChatGPT, Cursor y Copilot

Lo más importante

Lo más útil de hoy, aunque se anunció el 22 de octubre y aún no lo habíamos contado, es que Anthropic ha cedido Agent Skills a la Agentic AI Foundation (AAIF), una fundación independiente. Una skill es una carpeta con un archivo `SKILL.md`. Ese archivo explica a un agente (un asistente de IA que ejecuta tareas por su cuenta, no solo responde preguntas) cómo hacer algo concreto. La carpeta también guarda los scripts o documentos de referencia que necesite. Más de 70 plataformas ya la admiten, entre ellas ChatGPT, Cursor, GitHub Copilot y VS Code. En la práctica, si escribes una skill para preparar informes con el formato de tu empresa o para revisar código según tus normas, puedes usarla en varias herramientas sin reescribirla. Como ahora la gestiona una fundación, ya no depende de una sola empresa. Para empezar, crea una carpeta con un `SKILL.md` que contenga las instrucciones en texto normal y colócala en el directorio de skills de tu herramienta. Disponibilidad: es un estándar abierto y funciona en España en todas las herramientas citadas.

Si usas las vistas previas HTML de ChatGPT (la función que antes se llamaba Canvas y que muestra mini-apps interactivas dentro del chat), conviene que leas esto. Parameter Labs ha explicado cómo consiguió tomar el control de cuentas ajenas. Estas mini-apps se ejecutan en un sandbox (un espacio aislado que impide que su código acceda al resto de la página y a tus datos). El ataque aprovechaba MathLive, una librería que OpenAI usa para las gráficas. MathLive trae un teclado virtual que se puede activar desde dentro del espacio aislado. El código que recibía esas órdenes insertaba HTML sin filtrarlo, así que se podía meter código en la página principal de ChatGPT. La lección práctica: desconfía de las vistas previas generadas a partir de contenido de terceros, como webs o documentos que no conoces. Por lo que se publica, no queda claro si ya está corregido. Este tipo de informes suele salir después del parche, pero no podemos confirmarlo. Afecta igual a los usuarios en España.

Para quien trabaja con datos, datasette-llm 0.1a9 facilita empezar con Datasette Agent, una herramienta que te deja preguntar en lenguaje natural a bases de datos SQLite con ayuda de un LLM (modelo de lenguaje como GPT o Claude). Ahora usa automáticamente el modelo que tengas por defecto en la herramienta LLM de Simon Willison, así que basta con `uvx --with datasette-agent datasette content.db --internal internal.db`. Es código abierto y funciona desde cualquier país. Solo necesitas la clave de API (la credencial para usar el modelo desde un programa) del proveedor que elijas.

Tendencias y patrones

Los asistentes de IA que funcionan por mensajes de texto están de moda, pero los números todavía no acompañan. Zest, una app de recomendación de restaurantes, ha lanzado un "conserje" al que escribes por SMS y que te sugiere sitio y reserva mesa, en la línea de Instinct o Poke. Su fundador lo resume así: "el agente es ahora el producto". No hay datos de que funcione en España. Pero DoorDash ha contado que solo ha recibido "varios cientos" de pedidos hechos por agentes, frente a unos 3 millones de entregas diarias. Y Ollie, un asistente por texto centrado en la privacidad, cierra el 6 de noviembre. Si lo usabas, guarda lo que necesites antes de esa fecha.

La otra tendencia son los agentes que trabajan durante días. Arca, que aplica IA al trabajo financiero, explica que sus agentes llevan tareas largas gracias a una memoria persistente (recuerdan lo hecho entre sesiones) y a un harness propio (el código que rodea al modelo y gestiona sus herramientas, su memoria y sus pasos). Hasta le dan la vuelta a la relación habitual: es el agente el que pregunta a la persona cuando necesita algo. Por su parte, Anthropic ha ampliado su Cyber Verification Program a tres niveles. Los profesionales de seguridad verificados pueden usar Claude Opus 5.5 y Sonnet con menos bloqueos de los clasificadores (filtros automáticos que rechazan peticiones que parecen peligrosas), algo útil para auditorías y pruebas de intrusión. Hay un programa equivalente para investigación en biología. Ambos se solicitan en la web de Anthropic y el anuncio no especifica restricciones por país.

Para profundizar

  • SKILL.md — el formato de las Agent Skills; con unas pocas instrucciones bien escritas se mejora mucho a cualquier agente compatible.
  • Agentic AI Foundation (AAIF) — la fundación que mantendrá el estándar; interesa seguirla para ver qué otras piezas de agentes se estandarizan.
  • Datasette Agent — una forma sencilla de "hablar" con tus propias bases de datos usando cualquier LLM.
  • Cyber Verification Program — acceso a Claude con menos restricciones para equipos de ciberseguridad verificados.
  • Harness de agentes — la capa de código alrededor del modelo; entenderla ayuda a montar agentes que aguanten tareas largas.
