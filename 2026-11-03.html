Titular del día

ChatGPT junta sus pestañas Chat y Work para que pases de la idea al trabajo terminado sin cambiar de pantalla

Lo más importante

OpenAI va a fusionar las pestañas Chat y Work de ChatGPT. Ahora mismo la app de escritorio es un pequeño laberinto. Tiene una sección de ChatGPT y otra de Codex (su herramienta para programar), y dentro de la primera hay otras dos pestañas. Con el cambio, todo queda en un único espacio. Puedes empezar charlando sobre una idea y pedirle que la lleve hasta el final: añades tus archivos, conectas plugins (extensiones que enlazan ChatGPT con otros servicios) y le pides que monte una web, prepare una presentación o haga gestiones en internet por ti. Ahí funciona como un agente (una IA que no solo responde, sino que ejecuta tareas por su cuenta). Según el email que OpenAI ha enviado a sus usuarios, llegará primero a un grupo reducido para recoger opiniones y después a todo el mundo. No hay datos sobre España. Si todavía no te aparece, toca esperar.

Si te manejas con la terminal, Simon Willison ha publicado llm 0.37, su herramienta CLI (se usa escribiendo órdenes en la terminal) y librería de Python para hablar con modelos de IA. Reúne dos meses de mejoras:

  • Añade gpt-6.1-sol y gpt-6.1-terra.
  • Trae un comando nuevo, `llm openai endpoint add`, para conectar cualquier modelo con un endpoint compatible con OpenAI. Un endpoint es la dirección a la que se envían las peticiones, y como muchos proveedores copian el formato de OpenAI, sirve para casi todos.
  • El modelo por defecto pasa a ser gpt-6-luna, que cuesta la mitad que el anterior, gpt-5.6-luna.
  • Los embeddings (representaciones numéricas de un contenido que permiten buscar por significado) aceptan ya distintos tipos de archivo. Hace falta para modelos como Gemini Embedding 2, que trabaja con texto, audio, imágenes y vídeo.

Se actualiza con `pip install -U llm`. Es software libre y funciona desde España con tu propia clave de API (la "llave" que te da cada proveedor para usar sus modelos desde tus programas).

El domingo hablamos de las Agent Skills (paquetes de instrucciones que enseñan a tu asistente a hacer una tarea concreta). Si te quedaste con ganas de probarlas, aquí tienes por dónde empezar. Garry Tan, CEO de Y Combinator, ha publicado gratis en GitHub gstack, su colección de 23 skills para Claude Code. Tan cuenta que gasta entre 100.000 y 200.000 dólares al año en tokens (las unidades en que se mide y se cobra el texto que procesan los modelos). Usa agentes para investigar, preparar entrevistas y programar, así que es la caja de herramientas de alguien que lo exprime a fondo. Está pensado para Claude Code y, como el repositorio es público, puedes descargarlo desde España sin problema.

Tendencias y patrones

Los agentes salen caros, y empieza a notarse en lo que pagas. Este fin de semana, usuarios de Grok Bot, el agente de IA que comercializa SpaceX, vieron su límite semanal saltar del 50 % al 100 % sin haberlo tocado. Elon Musk confirmó que no era un fallo: servirlo costaba demasiado para lo que ingresaba. Al otro extremo están los 200.000 dólares de Tan y Pando, un sistema compatible con Git (la herramienta estándar para guardar versiones de código) que OpenAI ha creado para el volumen de desarrollo que permite Codex. La lección práctica es que una tarifa plana para agentes puede recortarse sin aviso, así que conviene vigilar tu consumo.

También cambian las reglas sobre lo que puede hacer la IA. La semana pasada, Anthropic añadió un nuevo system prompt (las instrucciones de fondo que el modelo recibe antes de tu conversación) para que Claude no recree videojuegos concretos que ya existen. Si lo usas para hacer juegos, inventar uno propio sigue funcionando, pero pedirle que clone uno concreto ya no. Va en la línea de su actualización de la política de uso de octubre, que añade ejemplos de cómo se aplican las normas ahora que Claude hace trabajos más largos y autónomos. Por otro lado, OpenAI ha presentado LifeVal, un benchmark (prueba estandarizada para comparar modelos) que mide algo más cercano a tu vida que las matemáticas: si la IA te ayuda de verdad a buscar guardería, ordenar tus finanzas o hacer papeleo con la administración. Google empuja en esa dirección con Dreambeans, una app que crea historias ilustradas a partir de tu Gmail, tu Calendar o tus fotos. Acaba de llegar a India, su primer país fuera de EE. UU., y en España sigue sin estar disponible.

Para profundizar

  • gstack — las 23 skills de Claude Code de Garry Tan; un buen ejemplo de cómo organizar instrucciones reutilizables para un agente.
  • llm openai endpoint add — el comando nuevo de llm para conectar desde la terminal cualquier proveedor compatible con OpenAI.
  • Gemini Embedding 2 — modelo de embeddings que trabaja con texto, audio, imágenes y vídeo; sirve para buscar por significado en archivos de distintos tipos.
  • LifeVal — el nuevo benchmark de OpenAI sobre tareas cotidianas, para ver cómo de útiles son los modelos fuera del trabajo técnico.
  • Evals sin trazas (Legora) — cómo prueba Legora su agente para abogados sin poder ver el registro paso a paso de lo que hace, porque los datos son de los clientes. Las evals son pruebas para medir si un agente hace bien su trabajo. Lo explica su CTO, Jacob Lauritzen, en dos episodios de Latent Space.
